# CO2 Assignment — Brute-Force and Exhaustive-Search Techniques

This repository contains Q1–Q7 pseudocode, Python implementations, execution evidence, raw experimental data, graphs, and the final report.

## Structure
- `Q1_Sorting_Algorithms/` — Selection, Bubble, and Insertion Sort comparison
- `Q2_Sequential_Search/` — position, miss, and list-size experiments
- `Q3_Brute_Force_String_Matching/` — three text/pattern conditions
- `Q4_Brute_Force_Closest_Pair/` — pair enumeration and theoretical count
- `Q5_Brute_Force_Convex_Hull/` — supporting-line geometric test
- `Q6_Exhaustive_Search/` — exhaustive 0-1 knapsack
- `Q7_Day4_Design_Challenge/` — sequential lookup redesigned with a hash index
- `Final_Report/CO2_Assignment_Report.docx` — compiled report
- `Experimental_Data/` — CSV operation-count data
- `Graphs/` — performance growth plots
- `Output_Screenshots/` — execution output screenshots

## Run
Requires Python 3.9+ and no third-party packages for the algorithm programs.

From the repository root:
```bash
python Q1_Sorting_Algorithms/Implementation_Code/main.py
python Q2_Sequential_Search/Implementation_Code/main.py
python Q3_Brute_Force_String_Matching/Implementation_Code/main.py
python Q4_Brute_Force_Closest_Pair/Implementation_Code/main.py
python Q5_Brute_Force_Convex_Hull/Implementation_Code/main.py
python Q6_Exhaustive_Search/Implementation_Code/main.py
python Q7_Day4_Design_Challenge/Implementation_Code/main.py
```
