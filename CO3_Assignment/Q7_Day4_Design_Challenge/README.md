# Q7 – Day-4 Design Challenge

**Important:** The assignment brief provided to us lists the design stages but does not state the actual Day-4 problem. Insert the exact problem statement supplied by the faculty before completing the algorithm.

## Stage 1 – Independent proposals (complete before discussion)
- `Student_A_Initial_Design/`: decomposition, base case, returned information, combine strategy.
- `Student_B_Initial_Design/`: decomposition, base case, returned information, combine strategy.

## Stage 2 – Design comparison
Use `Design_Comparison/` to record agreements, differences, strengths, weaknesses, missing cases and ideas retained.

## Stage 3 – Joint final design
Use `Joint_Final_Design/` for the decomposition, subproblems, base case, returned information, combine operation and final pseudocode.

## Stage 4 – Validation
- Student A: formulate and solve recurrence; explain asymptotic complexity.
- Student B: correctness tests, implementation/instrumentation and baseline comparison where feasible.

## Stage 5–6 – Cross-defence and evaluation
Both students should explain the other's responsibility and evaluate when D&C is appropriate, what work it reduces, recursion costs and limitations.
